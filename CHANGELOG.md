# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [semantic versioning](https://semver.org/).

Version numbers cover three things that can break separately: the spec format (`version` in a spec), the player, and the skill's instructions. A change that makes existing specs invalid is a major version.

## [0.1.0] - 2026-11-11

First release.

### Added

- The `visualize-anything` skill: `SKILL.md` with a six-step workflow, `references/spec.md` (the spec format) and `references/method.md` (how to model a subject).
- `assets/player.html`: a single-file, dependency-free player with a 2.5D scene, an animated token per step, a sequence timeline, an inspector (fields, payload, state tables, notes), status chips, distinct failure steps, playback controls, keyboard shortcuts, light and dark themes, and a phone layout.
- `scripts/validate.mjs` and `scripts/build.mjs` (Node 18 or later, no dependencies).
- Three example specs with built HTML: TCP three-way handshake, OAuth 2.0 authorization code flow with PKCE, hash map collision resolution.
- Adapters generated by `scripts/sync.mjs`: a Claude Code plugin and marketplace manifest, a portable root `plugin.json`, an `AGENTS.md` snippet and a Copilot prompt file.
- Evals: trigger prompts, behaviour cases with machine-checkable assertions, an offline checker and an opt-in live runner.
- A release workflow: pushing a version tag publishes a GitHub release with the skill folder as a ZIP for upload to the Claude apps.
- CI that validates and rebuilds the examples, checks the adapters are in sync and runs the offline evals.
