## Explainers can be wrong

An explainer is a simplified model written by an AI agent or a person. It can contain mistakes, and it always leaves things out. Check every explainer against the primary sources it lists (the standard, the official documentation, the source code) before you rely on it for a design, an implementation, a security decision, an exam answer or anything else that matters. If an explainer and a primary source disagree, the primary source is right.
